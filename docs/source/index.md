# PyFracVAL

<img src="_static/logo.png" alt="PyFracVAL Logo" width="50%">

PyFracVAL generates three-dimensional fractal-like aggregates of mono- and polydisperse primary particles using a particle-cluster/cluster-cluster aggregation (PCA/CCA) strategy. The implementation follows the FracVAL algorithm {cite:p}`Moran2019FracVAL`, with morphology conventions drawn from {cite:p}`Filippov2000Tunable`.
